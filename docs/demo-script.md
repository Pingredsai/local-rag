# LocalRAG 演示脚本

> 目标：在 60 秒到 3 分钟内证明三件事：
> 1. 文档可以上传并自动索引；
> 2. 回答来自文档，并显示来源；
> 3. 运行时数据留在本地部署环境。

---

## 演示前准备

- 服务地址：`http://localhost:8080`
- 演示资料：`demo/nova-employee-handbook.md`
- 已知问题及答案：
  - 问题：星云科技正式员工每年有多少天年假？
  - 答案：15 天。
  - 问题：内部文档可以上传到公有云 AI 吗？
  - 答案：不可以，内部文档、客户资料、源代码和未公开财务数据不得上传到任何公有云 AI 服务。
  - 问题：员工每周最多可以远程办公几天？
  - 答案：2 天。

如果演示前需要重新生成截图和视频：

```powershell
npm install
$env:PLAYWRIGHT_CHANNEL='msedge'
npm run capture
```

## 60 秒快速演示

### 0-10 秒：打开系统

打开 `http://localhost:8080`。

话术：

> 这是一个完全在本地运行的知识库问答系统。浏览器、向量库和大模型都在同一个部署环境里。

### 10-22 秒：上传文档

点击“上传文档”，选择 `nova-employee-handbook.md`。

话术：

> 系统会自动完成解析、切块、向量化和入库。这里可以看到索引了 3 个文本块。

### 22-38 秒：提问并展示来源

输入：

```text
星云科技正式员工每年有多少天年假？
```

话术：

> 注意，它不是直接让大模型自由回答，而是先从文档中检索相关片段，再基于这些片段生成答案。右侧显示的就是命中的来源和相似度。

### 38-50 秒：第二问

输入：

```text
内部文档可以上传到公有云 AI 吗？
```

话术：

> 回答来自同一份制度文件。来源引用让答案可以追溯，这比单纯的聊天机器人更适合企业内部知识库。

### 50-60 秒：收尾

话术：

> 首次安装需要下载镜像和模型；运行时不调用外部 AI API。可以把镜像、模型和数据目录一起复制到内网环境。

## 3 分钟完整演示

1. 介绍问题：律所、医院、财税、制造业不能把内部文档上传到云端 AI。
2. 打开系统，说明部署边界：Qdrant + Ollama + FastAPI。
3. 上传演示文档，展示索引结果。
4. 提问年假问题，展开来源引用。
5. 提问信息安全问题，说明“回答必须基于资料”。
6. 打开架构说明 `docs/architecture.md`，解释索引和问答两条流水线。
7. 说明配置：Embedding 用 `bge-m3`，生成模型可替换为 Qwen 的 1.5B、3B、7B 等版本。
8. 说明运行边界和当前限制：文本型 PDF、单知识库、尚未实现权限体系和 OCR。
9. 收尾：先做小范围 POC，用客户真实文档验证检索质量，再决定是否进入正式部署。

## 现场话术

### 一句话价值

> LocalRAG 不是把大模型放在云端，而是把知识库和大模型一起放进你的内网。

### 为什么不是普通聊天机器人

> 普通聊天机器人容易编造。LocalRAG 先检索文档，再基于命中片段回答，并把来源展示出来。

### 数据边界

> 运行时不依赖第三方 AI API，不需要把文档发给外部服务。首次安装需要联网拉取 Docker 镜像和模型，之后可以准备离线包。

### 交付形态

> 当前是一套 Docker Compose 模板。交付时可以替换模型、调整切块参数、接入客户已有文档目录，并按需要补充权限和审计。

---

## 不要说的内容

- 不要说“支持所有 PDF”；当前只保证文本型 PDF，扫描件需要 OCR。
- 不要说“生产级权限体系已完成”；当前版本没有多租户和权限模块。
- 不要说“任何问题都能答对”；RAG 的效果取决于文档质量和切块策略。
- 不要用未经授权的真实客户资料做演示。
