LRLocalRAG
PRIVATE KNOWLEDGE BASE · POC

用你们自己的文档，
验证一套本地 AI 知识库

在不把内部资料交给公有云的前提下，验证文档解析、语义检索和带来源回答是否能真正帮助团队找到资料。

适用场景 财税 / 律所 / 制造 / 内网POC 周期 5-10 个工作日验证方式 10-20 个真实问题

这次 POC 要验证什么

  • 你们约定格式的文档能否被正确解析和切块。
  • 真实问题能否检索到真正相关的资料片段。
  • 回答是否能给出可核验的来源，而不是“看起来像”。
  • 在你们现有机器或测试环境上，响应是否可接受。

POC 交付内容

本地环境部署FastAPI + Qdrant + Ollama，Docker Compose 启动。
文档索引文档解析、切块、本地向量化和来源展示。
测试问题集双方确认 10-20 个代表性问题并记录结果。
评估报告可用性、限制、问题清单和下一步建议。

客户需要提供

10-50 份脱敏文档10-20 个真实问题测试机器或环境1 位业务对接人
参考费用：¥3,000-8,000以范围确认单为准；如后续进入正式部署，POC 费用可抵扣。客户负责硬件、网络和脱敏资料。

数据边界

文档、向量和模型运行在客户自有环境。首次安装需要联网拉取镜像和模型；初始化完成后，运行时不调用公有云 AI API。
